## Featured projects

### 📊 [Excel Data Tools](https://github.com/mogtderi/excel-data-tools)
Three desktop apps (Tkinter) for comparing, merging and auto-completing large Excel lists.
Handles Persian/Arabic character and digit normalization, wide-to-long reshaping and styled Excel output.

### ✋ [Hand Gesture Capture](https://github.com/mogtderi/hand-gesture-capture)
Real-time hand tracking with MediaPipe: gesture-triggered photo capture (fist, open palm, thumbs up, peace) and an "air drawing" mode with the index finger.

### 📡 [Ultrasonic Radar (ESP32)](https://github.com/mogtderi/ultrasonic-radar)
A 180° scanning radar built from an ESP32, HC-SR04 and servo, with a live military-style display in Processing.
Includes a hardware write-up covering the power-supply issue I hit and how I fixed it.
